다양한 AI 프롬프트를 체계적으로 정리하고 공유하는 저장소입니다.
A repository for systematically organizing and sharing various AI prompts.

## 🎯 소개 (Introduction)

이 저장소는 AI와의 효과적인 상호작용을 위한 프롬프트를 체계적으로 정리합니다.
각 프롬프트는 설명, 사용 예시, 그리고 목적과 함께 문서화되어 있습니다.

This repository systematically organizes prompts for effective AI interaction.
Each prompt is documented with descriptions, usage examples, and purposes.

## 📁 프롬프트 구조 (Prompt Structure)

각 프롬프트는 다음과 같은 구조로 정리됩니다:

```
prompts/
├── category/
│   ├── prompt-name.md
│   └── ...
└── ...
```

### 프롬프트 템플릿 (Prompt Template)

각 프롬프트 파일은 다음 형식을 따릅니다:

```markdown
# [프롬프트 제목]

## 설명 (Description)
프롬프트의 목적과 용도를 설명합니다.

## 카테고리 (Category)
- 분류: [카테고리명]
- 난이도: [초급/중급/고급]
- 용도: [용도 설명]

## 프롬프트 내용 (Prompt Content)
\```
[실제 프롬프트 내용]
\```

## 사용 예시 (Usage Example)
[프롬프트 사용 예시]

## 기대 결과 (Expected Output)
[기대되는 결과 설명]

## 태그 (Tags)
#tag1 #tag2 #tag3
```

## 🗂️ 카테고리 (Categories)

프롬프트는 다음 카테고리로 구분됩니다:

- **코딩 (Coding)**: 프로그래밍 관련 프롬프트
- **글쓰기 (Writing)**: 콘텐츠 작성 및 편집
- **번역 (Translation)**: 다국어 번역
- **분석 (Analysis)**: 데이터 및 텍스트 분석
- **교육 (Education)**: 학습 및 교육 자료
- **비즈니스 (Business)**: 업무 및 비즈니스 관련
- **창작 (Creative)**: 창의적 콘텐츠 생성
- **기타 (Others)**: 기타 범용 프롬프트

## 💡 사용 방법 (How to Use)

1. 원하는 카테고리의 프롬프트를 찾습니다
2. 프롬프트 파일을 열어 설명을 확인합니다
3. 프롬프트 내용을 복사하여 AI 도구에 사용합니다
4. 필요에 따라 프롬프트를 수정하여 활용합니다

## 🤝 기여 가이드 (Contribution Guide)

새로운 프롬프트를 추가하거나 기존 프롬프트를 개선하려면:

1. 이 저장소를 Fork 합니다
2. 새로운 브랜치를 생성합니다 (`git checkout -b add-new-prompt`)
3. 프롬프트 템플릿을 따라 새 파일을 작성합니다
4. 변경사항을 커밋합니다 (`git commit -m 'Add: [프롬프트 이름]'`)
5. 브랜치에 Push 합니다 (`git push origin add-new-prompt`)
6. Pull Request를 생성합니다

### 기여 규칙

- 템플릿 형식을 준수해주세요
- 적절한 카테고리에 배치해주세요
- 한글과 영문 설명을 모두 포함해주세요
