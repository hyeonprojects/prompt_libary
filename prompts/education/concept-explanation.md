# 학습 자료 설명 (Learning Material Explanation)

## 설명 (Description)
복잡한 개념을 이해하기 쉽게 설명하고 학습을 돕는 프롬프트입니다.

A prompt for explaining complex concepts in an easy-to-understand way.

## 카테고리 (Category)
- 분류: 교육 (Education)
- 난이도: 초급
- 용도: 개념 학습 및 이해 증진

## 프롬프트 내용 (Prompt Content)
```
다음 주제/개념을 [대상 수준: 초등학생/중학생/고등학생/대학생/일반인]이 
이해할 수 있도록 설명해주세요:

주제: [학습할 주제나 개념]

다음 형식으로 설명해주세요:
1. 간단한 정의 (한 문장으로)
2. 일상생활의 비유나 예시
3. 핵심 개념 상세 설명
4. 실제 적용 사례
5. 흔한 오해나 주의점
6. 추가 학습을 위한 관련 주제

가능하다면 다이어그램이나 단계별 설명을 포함해주세요.
```

## 사용 예시 (Usage Example)
```
주제: 양자 역학의 중첩 원리
대상 수준: 고등학생
```

또는

```
주제: 블록체인 기술의 작동 원리
대상 수준: 일반인
```

## 기대 결과 (Expected Output)
- 명확하고 이해하기 쉬운 설명
- 적절한 비유와 예시
- 단계별로 구조화된 내용
- 개념을 보여주는 실제 사례
- 추가 학습 자료 제안

## 활용 팁 (Tips)
- 학습자의 수준을 정확히 지정하면 적절한 난이도의 설명을 받을 수 있습니다
- 특정 부분에 대해 더 깊은 설명이 필요하다면 후속 질문을 하세요
- 시각적 설명이 필요한 경우 다이어그램 요청을 명시하세요
