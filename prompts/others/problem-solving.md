# 문제 해결 브레인스토밍 (Problem Solving Brainstorming)

## 설명 (Description)
복잡한 문제에 대한 창의적이고 실용적인 해결책을 찾기 위한 프롬프트입니다.

A prompt for finding creative and practical solutions to complex problems.

## 카테고리 (Category)
- 분류: 기타 (Others)
- 난이도: 중급
- 용도: 문제 해결, 아이디어 발상

## 프롬프트 내용 (Prompt Content)
```
다음 문제에 대한 다양한 해결책을 브레인스토밍해주세요:

문제 설명: [해결하고자 하는 문제]
맥락/배경: [문제가 발생한 상황이나 환경]
제약 조건: [예산, 시간, 리소스 등의 제한사항]
목표: [달성하고자 하는 결과]

다음 방식으로 분석해주세요:
1. 문제의 핵심 원인 분석
2. 최소 5가지 이상의 해결책 제시
3. 각 해결책의 장단점 평가
4. 실행 가능성 및 예상 효과
5. 권장 솔루션 및 실행 계획

창의적이면서도 실용적인 접근을 병행해주세요.
```

## 사용 예시 (Usage Example)
```
문제: 팀원들의 회의 참여도가 낮음
맥락: 원격 근무 환경, 주 2회 정기 회의
제약 조건: 추가 예산 없음, 회의 시간은 1시간 이내
목표: 회의 참여도 50% 향상
```

## 기대 결과 (Expected Output)
- 문제의 근본 원인 파악
- 다양한 관점의 해결책
- 각 옵션의 실행 가능성 평가
- 단계별 실행 계획
- 예상되는 장애물과 대응 방안

## 활용 팁 (Tips)
- 문제를 구체적으로 정의할수록 더 실용적인 해결책을 얻습니다
- 이전에 시도했던 방법이 있다면 함께 공유하세요
- 이해관계자나 영향을 받는 대상을 명시하면 도움이 됩니다
- 혁신적인 솔루션을 원한다면 제약 조건을 유연하게 설정하세요
