# 블로그 글 작성 (Blog Post Writing)

## 설명 (Description)
특정 주제에 대한 흥미롭고 유익한 블로그 글을 작성하기 위한 프롬프트입니다.

A prompt for writing interesting and informative blog posts on specific topics.

## 카테고리 (Category)
- 분류: 글쓰기 (Writing)
- 난이도: 초급
- 용도: 블로그 콘텐츠 생성

## 프롬프트 내용 (Prompt Content)
```
다음 주제로 블로그 글을 작성해주세요:

주제: [주제를 입력하세요]
대상 독자: [독자층을 입력하세요]
글의 톤: [공식적/친근한/전문적 등]
길이: [단어 수 또는 분량]

다음 구조로 작성해주세요:
1. 눈길을 끄는 제목
2. 흥미로운 서론 (독자의 관심을 끌 수 있는)
3. 본문 (2-3개의 주요 포인트)
4. 실용적인 예시나 팁
5. 요약 및 행동 촉구 결론

글은 읽기 쉽고 SEO 친화적으로 작성해주세요.
```

## 사용 예시 (Usage Example)
```
주제: 재택근무 생산성 향상 방법
대상 독자: 재택근무를 시작한 직장인
글의 톤: 친근하고 실용적
길이: 1000-1500자
```

## 기대 결과 (Expected Output)
- 매력적인 제목과 서론
- 구조화된 본문 내용
- 실용적인 팁과 예시
- 독자 행동을 유도하는 결론
- SEO 키워드가 자연스럽게 포함된 글

## 활용 팁 (Tips)
- 대상 독자를 명확히 정의하면 더 타겟팅된 콘텐츠를 얻을 수 있습니다
- 원하는 키워드를 미리 지정하면 SEO 최적화에 도움이 됩니다
- 글의 목적(정보 전달, 제품 소개 등)을 명시하면 더 적합한 결과를 얻습니다
