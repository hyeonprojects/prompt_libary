# 데이터 분석 및 인사이트 도출 (Data Analysis and Insights)

## 설명 (Description)
데이터를 분석하고 의미 있는 인사이트를 도출하기 위한 프롬프트입니다.

A prompt for analyzing data and deriving meaningful insights.

## 카테고리 (Category)
- 분류: 분석 (Analysis)
- 난이도: 중급
- 용도: 데이터 해석 및 의사결정 지원

## 프롬프트 내용 (Prompt Content)
```
다음 데이터를 분석하고 주요 인사이트를 도출해주세요:

[데이터 또는 데이터 설명을 입력하세요]

분석 요구사항:
1. 주요 트렌드 및 패턴 식별
2. 이상치(outlier) 발견 및 설명
3. 데이터 간 상관관계 분석
4. 실행 가능한 인사이트 제공
5. 시각화 제안 (어떤 차트/그래프가 적합한지)

분석 결과를 다음 형식으로 제시해주세요:
- 핵심 발견사항 (요약)
- 상세 분석
- 비즈니스 시사점
- 권장 행동 사항
```

## 사용 예시 (Usage Example)
```
월별 웹사이트 방문자 데이터:
1월: 10,000명
2월: 12,000명
3월: 15,000명
4월: 14,500명
5월: 18,000명
6월: 22,000명

각 월별 전환율:
1월: 2.5%
2월: 2.8%
3월: 3.2%
4월: 3.0%
5월: 3.5%
6월: 4.0%
```

## 기대 결과 (Expected Output)
- 명확한 트렌드 분석
- 수치 기반의 객관적인 인사이트
- 비즈니스 의사결정에 도움이 되는 제안
- 추가 분석이 필요한 영역 식별
- 적절한 시각화 방법 제안

## 활용 팁 (Tips)
- 데이터의 컨텍스트(산업, 목적 등)를 함께 제공하면 더 의미 있는 분석을 얻습니다
- 특정 질문이나 가설이 있다면 명시하여 집중적인 분석을 요청할 수 있습니다
- 시계열 데이터의 경우 기간을 명확히 표시하세요
