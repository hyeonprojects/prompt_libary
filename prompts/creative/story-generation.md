# 창의적 스토리 생성 (Creative Story Generation)

## 설명 (Description)
독창적이고 흥미로운 스토리를 창작하기 위한 프롬프트입니다.

A prompt for creating original and engaging stories.

## 카테고리 (Category)
- 분류: 창작 (Creative)
- 난이도: 중급
- 용도: 소설, 시나리오, 단편 스토리 작성

## 프롬프트 내용 (Prompt Content)
```
다음 조건으로 창의적인 스토리를 작성해주세요:

장르: [SF/판타지/로맨스/미스터리/스릴러/드라마 등]
길이: [단편/중편/장편 개요]
주요 요소:
- 주인공: [간단한 설명]
- 배경: [시간, 장소]
- 갈등: [주요 갈등이나 문제]
- 테마: [다루고 싶은 주제]

스토리 구조:
1. 흥미로운 도입부
2. 갈등의 전개
3. 클라이맥스
4. 해결 및 결말

독창적이고 예측 불가능한 전개를 포함하되, 논리적 일관성을 유지해주세요.
```

## 사용 예시 (Usage Example)
```
장르: SF 미스터리
길이: 단편 (3000자 내외)
주요 요소:
- 주인공: 시간여행 탐정
- 배경: 2157년 뉴욕
- 갈등: 과거에서 온 범죄를 해결해야 함
- 테마: 시간의 역설과 인과관계
```

## 기대 결과 (Expected Output)
- 매력적인 캐릭터와 설정
- 흥미진진한 플롯 전개
- 독창적인 아이디어와 반전
- 감정적 몰입을 유도하는 서술
- 만족스러운 결말

## 활용 팁 (Tips)
- 원하는 분위기나 감정을 명시하면 더 적합한 스토리를 얻습니다
- 피하고 싶은 클리셰가 있다면 미리 알려주세요
- 특정 메시지나 교훈을 담고 싶다면 테마를 명확히 하세요
- 시리즈물을 원한다면 세계관 설정을 상세히 요청하세요
