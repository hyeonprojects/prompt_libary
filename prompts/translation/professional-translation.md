# 전문 문서 번역 (Professional Document Translation)

## 설명 (Description)
전문 용어와 문맥을 고려한 고품질 번역을 위한 프롬프트입니다.

A prompt for high-quality translation considering technical terms and context.

## 카테고리 (Category)
- 분류: 번역 (Translation)
- 난이도: 중급
- 용도: 전문 문서 및 기술 문서 번역

## 프롬프트 내용 (Prompt Content)
```
다음 텍스트를 [원본 언어]에서 [목표 언어]로 번역해주세요.

번역 시 다음 사항을 준수해주세요:
1. 전문 용어는 해당 분야의 표준 용어를 사용
2. 원문의 뉘앙스와 톤을 유지
3. 문화적 맥락을 고려한 자연스러운 번역
4. 필요시 전문 용어에 대한 설명 추가

분야: [기술/법률/의료/비즈니스 등]

[여기에 번역할 텍스트를 입력하세요]

번역 결과와 함께 주요 전문 용어에 대한 용어집도 제공해주세요.
```

## 사용 예시 (Usage Example)
```
원본 언어: 영어
목표 언어: 한국어
분야: 기술 문서

텍스트: "The API endpoint returns a JSON response containing user data. 
Implement error handling for network timeouts and invalid tokens."
```

## 기대 결과 (Expected Output)
- 정확하고 자연스러운 번역
- 분야별 전문 용어의 적절한 사용
- 원문의 의도와 뉘앙스 보존
- 주요 용어에 대한 용어집
- 번역 시 특이사항이나 주의점 안내

## 활용 팁 (Tips)
- 문서의 분야를 명확히 지정하면 더 정확한 전문 용어 번역을 얻습니다
- 대상 독자(전문가/일반인)를 명시하면 적절한 수준의 번역이 가능합니다
- 기존 용어집이 있다면 함께 제공하여 일관성을 유지할 수 있습니다
